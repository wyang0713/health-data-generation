The following project was developed for the purpose of further developing skills in Python, Docker and PostgreSQL. </br>
Step 1: Using Pandas, and other libraries, the Python script generates synthetic patient and health data for each patient. Variables control how many records are generated. </br>
Step 2: The data is saved in CSV format. </br>
Step 3: Using Python, the CSV data is extracted and loaded into a staging table in a PostgreSQL database. </br>
Step 4: The staging data is transformed and loaded into production tables. </br>

<img width="2752" height="1536" alt="SyntheticDataProject" src="https://github.com/user-attachments/assets/87d551d0-3211-48b4-9fe3-0f9269a5004a" /> </br>

In this example, 10,000 unique patients were created. Afterwards, a health record was created for each patient everyday between 01/01/2014 and 12/31/2024 for a total of 40,180,000 rows. This process can be scaled up or down depending the amount of testing might be required. </br>
